# Cookie Inspector — 浏览器 Cookie 查看器插件

> 一款美观、安全、合规的浏览器扩展插件，帮助开发者和普通用户查看当前网站的所有 Cookie 信息。

---

## 功能介绍

### 核心能力

| 功能 | 说明 |
|------|------|
| **自动域名识别** | 读取当前标签页 URL，自动识别主域名并扩展查询子域名/父域名变体，获取完整的 Cookie 列表 |
| **Cookie 卡片展示** | 每个 Cookie 以独立卡片呈现，包含名称、值、域名、路径、过期时间、HttpOnly、Secure、SameSite 等全部属性 |
| **值折叠/展开** | Cookie 值默认折叠显示前 40 字符，防止页面被长字符串撑乱；点击「展开」查看完整值 |
| **彩色标签系统** | HttpOnly / Secure / Session / SameSite 等属性以彩色标签形式直观展示 |
| **实时搜索过滤** | 在搜索框输入关键字，实时按 Cookie 名称或所属域名过滤，高亮匹配文字，显示过滤后数量 |
| **一键复制** | 每个 Cookie 卡片右侧提供「复制名称」和「复制值」两个按钮，点击即复制到剪贴板，带 Toast 提示 |
| **导出 JSON** | 点击底部「导出」按钮，将当前筛选结果（全部或搜索过滤后的）下载为含域名+时间戳的 JSON 文件 |
| **一键刷新** | 点击刷新按钮，带旋转动画重新加载当前页面 Cookie 数据 |
| **统计面板** | 顶部实时显示 Cookie 总数、HttpOnly 数量、Secure 数量、Session 数量，一目了然 |
| **空状态处理** | 当当前页面无 Cookie 或搜索无结果时，显示友好的空状态提示 |
| **脱敏友好提示** | 插件仅展示 Cookie 信息，不采集、不上传、不后台传输任何数据 |

### 隐私说明

- **仅本地读取**：所有 Cookie 数据仅在用户本地浏览器中读取，不上传至任何服务器
- **仅当前标签页**：仅读取当前用户主动访问的标签页所属域名，不跨站采集
- **仅用户触发**：用户必须主动点击插件图标才会读取 Cookie，无静默采集
- **合规设计**：不提供批量采集、不绕过登录态、不导出可用于账号接管的完整凭证

## 支持网站类型

本插件基于浏览器标准 Cookie API，理论上支持所有使用 Cookie 存储数据的网站，包括但不限于：

| 类别 | 示例平台 |
|------|---------|
| 直播平台 | 抖音、Bilibili、虎牙直播、斗鱼、YY、企鹅电竞 |
| 电商平台 | 淘宝、天猫、京东、拼多多、唯品会、苏宁易购 |
| 社交平台 | 微博、知乎、小红书、豆瓣、贴吧 |
| 视频平台 | 优酷、腾讯视频、爱奇艺、芒果 TV |
| 新闻资讯 | 今日头条、腾讯新闻、网易新闻 |
| 邮箱服务 | QQ邮箱、163邮箱、Gmail（需登录后） |
| 开发者工具 | 任何使用 Cookie 的本地/线上网站 |

## 安装步骤

### Chrome 浏览器

1. 打开 Chrome，访问 `chrome://extensions`
2. 页面右上角开启 **「开发者模式」** 开关
3. 点击页面右上角的 **「加载已解压的扩展程序」** 按钮
4. 在弹出的文件选择器中，选择项目文件夹 `cookie-inspector`
5. 安装完成后，Chrome 工具栏右上角会出现 🧩 **拼图图标**
6. 访问任意网站，点击 🧩 图标即可打开 Cookie Inspector

### Edge 浏览器（Chromium 内核）

1. 打开 Edge，访问 `edge://extensions`
2. 页面左侧开启 **「开发人员模式」** 开关
3. 点击右上角的 **「加载已解压的扩展程序」** 按钮
4. 在弹出的文件选择器中，选择项目文件夹 `cookie-inspector`
5. 安装完成后，Edge 工具栏右上角会出现 🧩 **拼图图标**
6. 访问任意网站，点击 🧩 图标即可打开 Cookie Inspector

### 常见问题

| 问题 | 解决方案 |
|------|---------|
| 工具栏没有插件图标 | 点击 🧩 拼图图标，在列表中找到「Cookie Inspector」，点击📌固定到工具栏 |
| 显示「无法读取 Cookie」 | 检查页面是否完全加载，确认该网站使用了 Cookie（非 localStorage） |
| Cookie 数量为 0 | 部分网站使用 HTTP-Only Cookie，或跨域限制导致无法读取 |
| 插件刷新后数据不更新 | 点击底部 🔄 刷新按钮重新加载 |
